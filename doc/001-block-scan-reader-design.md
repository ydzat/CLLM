# 001 · 块扫描阅读器（Block-Scan Reader）设计文档

> 状态：Draft v0.1
> 日期：2026-08-31
> 范围：定义完整架构规格，供代码实现与正确性推理。所有组件均以数学/计算机语言表达。

---

## 1. 目标

用中文「信息密度高、可块状扫读、词序容忍」的特性，设计并训练一个在**算力-质量前沿**上优于同规模标准 transformer 的模型，覆盖阅读（编码）与生成（解码）。

---

## 2. 设计哲学（三条不变式）

1. **信息密度最大化** — 字符级分词：一个语义单位 = 一个 token。
2. **位置稀疏化** — 位置只在「块」粒度定义；块内以「内容/角色」而非「顺序」组织。
3. **算力不均等化** — 注意力线性化，FFN 条件化（易块扫过、难块精读）。

---

## 3. 设计决策

### D1 · 字符级分词（已定）

中文的「词」不是文本中标记出来的原生单位，而是后训练/后推导出来的切分。字符级输入让模型**自己从字符发现词边界**，与「词是后训练出来的」一致；同时信息密度最大（一汉字 = 一语义单位 = 一 token）。

### D2 · 块内交互：必要性论证（已定：必要，但内容型而非位置型）

**问题**：块内 token 是否需要跨 token 交互？能否只用 sum-pool + 逐 token FFN？

**结论**：必要，且必须是**内容型（置换不变）**交互；纯 sum-pool 不足。

**证明（反例法）**：

1. 块必须能从字符集合重构**角色指派**（例：从 `{我,吃,饭}` 输出「施事=我，动作=吃，受事=饭」）。
2. 角色指派是「角色 → token」的匹配/选择，本质是**关系运算**。
3. 逐 token FFN：每个 token 独立处理，无跨 token 信息 → 无法计算匹配。
4. sum-pool：`z = MLP(Σ h_i)` 是对称函数，把集合压成单向量 → 无法表示「哪个 token 是施事」。
5. ∴ 必须存在**内容型跨 token 交互**（注意力 = 软匹配），用于「哪个 token 填哪个角色」。
6. 该交互应**置换不变**（内容决定角色，顺序不决定）→ 即 Set Transformer / slot attention，而非带位置偏置的顺序注意力。

**代价（诚实声明）**：块内置换不变 ⇒ 模型对「仅由顺序区分」的意义是盲的（「狗追猫」与「猫追狗」是同一集合）。这与人类行为一致——大脑用先验自动纠错（「饭吃我」→「我吃饭」）——但会带来**可测量的准确率损失**，集中在「顺序歧义对」上。该代价随块大小 T 增大而增大（见 §6 核心权衡）。

### D3 · 生成方式（已定：离散扩散 / 迭代掩码填充）

见 §4.7。决策依据（图生成领域的历程，详见 §11）：

1. 图是无自然顺序的数据——每个图有 n! 种等价排序，自回归必须**强行选一个顺序**（GraphRNN 的 BFS、GRAN 的随机序），这个强加的顺序本身就是偏置来源（EDP-GNN、GraphVAE 都明确指出）。
2. 因此图生成整体**从自回归转向了离散扩散 / 迭代精炼**（DiGress、GraphARM、EDGE、SGDM），它天然置换等变。
3. 文本侧同样成立：Mask-Predict（arXiv:1904.09324）与 LLaDA（arXiv:2502.09992）已证明「迭代掩码填充」对语言可行。
4. 本模型的「块」= 图生成里的「无顺序对象」，slot 注意力输出 = set-to-sequence（TSPN arXiv:2006.16841、Slot Attention arXiv:2006.15055）。

**结论：非自回归离散扩散，O(K) 次前向替代 O(N) 步自回归。** 中文作为词序容忍语言，是这种并行生成最该受益的语种（H3）。

## 4. 完整规格

### 4.1 输入与 2D 布局

字符级分词，排成固定行宽 W 的网格：

```
x = (x_1, …, x_N),  x_i ∈ V
r_i = ⌊i / W⌋,  c_i = i mod W
```

H = ⌈N/W⌉ 行，`<pad>` 补成 H×W。

### 4.2 块（注视块）

T×T 的 tile 划分：

```
u_i = ⌊r_i / T⌋,  v_i = ⌊c_i / T⌋,  b(i) = (u_i, v_i)
```

块数 M = ⌈N / T²⌉。T 是「稀疏度旋钮」。

### 4.3 嵌入 + 稀疏位置编码

```
h_i^(0) = Embed(x_i) + P[u_i, v_i],   P ∈ R^{R×C×d}（可学习）
```

**唯一的位置信号**：位置定义在**块粒度**（R·C = N/T² 个位置，而非 N 个），块内所有 token 共享同一位置 → 块内置换不变。T=1 退化为逐 token 2D 位置；T 越大越「稀疏」。

### 4.4 层结构（重复 L 次）

每层五步。前四步为「扫」（廉价、无条件），第五步为「读」（昂贵、条件）。

**(a) 池化（粗扫描 / 提取主旨）** — DeepSets，置换不变：

```
z_b = MLP_pool( Σ_{i∈b} h_i^(ℓ−1) )
```

**(b) 全局稀疏块注意力（跳读）** — 只在块之间，掩码固定：

```
S(b) = { b' : max(|u−u'|, |v−v'|) ≤ 1 }                     (3×3 邻域)
     ∪ { b' : v' = v, u'−u ∈ {±2,±3,±4} }                  (跳行)
     ∪ { b' : u' = u, v'−v ∈ {±2,±3} }                     (跳列)

z_b ← z_b + Attn( z_b ; { z_{b'} : b' ∈ S(b) } )
```

|S| ≈ 19（常数）。跳行/跳列即「纵向跳 2–3 行」的机器版。

**(c) 广播** — 块级全局上下文注回 token：

```
h_i^(ℓ) = h_i^(ℓ−1) + z_{b(i)}
```

**(d) 路由（精读/跳读分水岭）**：

```
s_b = W_r z_b,   K = top-k_b { s_b }
```

**(e) 条件精读（仅选中块，α = k/M）**：

```
h_i^(ℓ) ← h_i^(ℓ) + SetAttn( h_i^(ℓ) ; { h_j^(ℓ) : j ∈ b } )    // 块内内容注意力，置换不变、无位置
h_i^(ℓ) ← h_i^(ℓ) + FFN( h_i^(ℓ) )                              // 条件 FFN
```

跳过块：只被广播更新，不过 SetAttn/FFN。**「扫」= 池化 + 稀疏注意力（O(N)）；「读」= 块内内容注意力 + FFN（O(N·d²)，仅 α 比例）。**

### 4.5 输出：槽位注意力（set-to-sequence）

编码是「集合」，但输出必须是「合理组合」（有序）。解码头用**槽位注意力**——每个槽位（角色）从块内 token 集合中**选择**自己的 token：

```
q_j = 可学习槽位向量,  j = 0..T²−1
a_{j,i} = softmax_i( q_jᵀ W_k h_i / √d )          // 槽位 j 关注哪些 token
logit_{b,j} = W_o Σ_i a_{j,i} W_v h_i              // 槽位 j 输出 token
```

**精确对应原话**：「阅读时不知道精确位置（集合），重组时产生合理顺序（槽位）。」槽位 = 「合理组合」中的角色位置，由内容（先验）而非顺序决定。

### 4.6 训练目标：块级掩码语言建模

随机掩掉 **15% 的整块**，用槽位注意力预测被掩块每个槽位的 token。损失 = 被掩块上的交叉熵。整块掩码强迫模型「从粗位置 + 邻居上下文重构整块的合理组合」。

### 4.7 生成：非自回归迭代填充

```
1. 全网格置 [MASK]
2. 一次前向并行预测所有 token
3. 保留高置信度预测，其余重新掩码
4. 重复 K ≈ 8–16 轮
```

**O(K) 次前向替代 O(N) 步自回归。** 图生成领域已证明：对无自然顺序的数据，自回归强加的顺序是有害的，并行迭代精炼（离散扩散）是更优解（§11 引用）。

## 5. 核心权衡：块大小 T

| T 增大 | T 减小 |
|---|---|
| 池化/稀疏效率更高（M = N/T² 更小） | 顺序损失更小（块内字符更少） |
| 块内顺序损失更大（「狗追猫/猫追狗」更多落进同一块） | 计算效率更低（接近逐 token） |

**T 是「顺序精度 ↔ 计算效率」的单一旋钮，也是整个设计的核心研究问题**：中文是否能比英文承受更大的 T（更粗的位置）而不掉质量。若成立，即「中文读得快」迁移成功——中文可以在同等质量下用更大的块、更少的算力。

---

## 6. 复杂度（每层）

| 部件 | dense transformer | block-scan |
|---|---|---|
| 注意力 | O(N²·d) | 块间 O(M·|S|·d) + 块内 O(αN·T²) ≈ **O(N)** |
| FFN | O(8N·d²) | O(**8α**·N·d²) |
| 池化+广播 | — | O(N·d) |
| 生成 | O(N) 步自回归 | **O(K)** 次前向 |

三个真提速点：注意力 O(N²)→O(N)；FFN 降到 α 比例（跳读 1−α）；生成 O(K)。

---

## 7. 正确性：数学保证 vs 待验证假设

**可证明正确（数学保证）**：

- 池化 `Σ + MLP` 是通用置换不变编码器（Zaheer et al. 2017）。
- 槽位注意力是 set-to-sequence 的标准机制（Set Transformer, Lee et al. 2019；Slot Attention, Locatello et al. 2020）。
- top-k 路由给出**精确 FLOPs 上界**（Mixture-of-Depths, 2024）。
- 稀疏块注意力覆盖短程（3×3）+ 长程（跳连接）。
- 块级 MLM（BERT）与迭代掩码解码（LLaDA / DiGress）均已验证。

**待实验验证（研究本身）**：

- **H1（核心）**：中文在块粒度位置（T>1）下质量不掉、英文掉。
- **H2（提速）**：中文语义负载集中于少数块，跳读率 (1−α) 可推高而不伤中文。
- **H3（生成）**：中文对并行填充比对英文更宽容。

## 11. 附录：图模型生成方式（D3 参考，已回填）

### 11.1 为什么图生成放弃了自回归（本设计 D3 的核心论据）

1. **无自然顺序 / 表示不唯一**：每个图有 n! 种等价节点排序，自回归必须选一个（GraphRNN 用 BFS），而「在集合上学习时，线性化顺序是敏感的」（Vinyals et al. 实测结论，GraphVAE 转引）。
2. **顺序偏置破坏置换不变性**：EDP-GNN 明确指出「现有图生成模型大多对所选排序不不变，导致学到的分布有偏」。
3. **成本与可扩展性**：GDSS 指出自回归「计算昂贵且无法刻画图的置换不变本质」；GraphARM 指出一次性扩散模型需全邻接矩阵入显存，而逐节点掩码扩散更快。
4. **长程瓶颈**：GRAN 用分块生成「绕开 RNN 序列本质带来的长程瓶颈」。
5. **误差累积 / 全局一致性差**：综述（arXiv:2401.15617）指出自回归「逐节点生成导致早停、忽略全局交互」。
